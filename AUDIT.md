## Доступность экранов

Общий контейнер навигации учитывает измеренную высоту нижней панели, системную навигацию и клавиатуру. При открытой клавиатуре нижняя панель скрывается. Убраны прежние фиксированные отступы, которые компенсировали перекрытие вручную.

В Bond Spam список устройств имеет ограниченную высоту, а остальное содержимое прокручивается. Панель управления измеряется по содержимому, кнопка Start доступна после выбора устройства. Экран запроса Bluetooth-разрешений тоже прокручивается при увеличении шрифта.

NFC-эмуляция привязана к активному экрану и прекращается при его закрытии или уходе приложения в фон. Активная метка хранится в памяти и не восстанавливается при новом запуске приложения.

## Проверки и границы результата

Автоматические тесты проверяют BLE-кадры, разбиение UTF-8 между пакетами, некорректные входные данные, HTTP byte ranges и реальную IEEE-базу производителей. Lint включён для release. Для AGP 8.9.1 используется анализатор UAST без K2, поскольку K2-анализ зависал на Compose; компилятор Kotlin не менялся. Проверка LocalContextGetResourceValueCall понижена до предупреждения с объяснением в app/lint.xml; остальные ошибки остаются блокирующими.

Итоговый прогон `:app:testDebugUnitTest :app:lintRelease :app:assembleRelease` завершился успешно за 6 мин 41 с. Все 13 тестов прошли. Release lint: 0 ошибок, 889 предупреждений, 15 информационных замечаний. `git diff --check` не обнаружил ошибок пробелов.

APK: `app/build/outputs/apk/release/app-release.apk`, версия 2.6 (26), размер 66 326 034 байта. Минимальный API 26, целевой API 36; включены ARMv7, ARM64, x86 и x86_64. Отладочный режим приложения выключен. `apksigner verify` подтвердил корректную v2-подпись существующим сертификатом Android Debug; `zipalign` завершился успешно. В упакованном манифесте проверен отдельный фильтр file URI для плагинов.

SHA-256 APK: `B88F811F972A8EE75FE3B2A782D19F37039507F7D56D88E4990513D4CC97344B`.

Проверка по исходникам не подтверждает совместимость с конкретным телевизором, NFC-меткой, принтером или Bluetooth-устройством. Во время итогового прогона ADB не обнаружил подключённый телефон; визуальная проверка разметки на устройстве не выполнена. Радиопередача, нагрузочные режимы и воздействия на окружающие устройства не запускались.

Оставшиеся предупреждения о старых Android API и стилях кода не равны ошибкам сборки. Крупные экранные файлы уменьшены, но дальнейшее разделение возможно по мере изменений отдельных функций. По стилю исходников нельзя достоверно установить, писал ли их человек или ИИ; из README удалены шаблонные обещания и неподтверждённые заявления.
